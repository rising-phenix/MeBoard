# MeBoard milestones

Milestones are ordered release gates, not calendar promises. Do not begin a later milestone by skipping failed acceptance criteria in an earlier one.

| Milestone | Goal | Exit condition |
|---|---|---|
| M0 | Repository and build foundation | Reproducible build, CI and module boundaries |
| M1 | Native IME skeleton | Enable/select keyboard and safely type |
| M2 | Keyboard UX | Layout, editor actions, themes and sizing |
| M3 | Privacy and local storage | Learning gate, Room schema and controls |
| M4 | Baseline prediction | Trie + unigram/bigram suggestions |
| M5 | Context and correction | Trigram, ranking and bounded correction |
| M6 | Algorithm experiments | Evaluated regression/tree/k-means/ANN prototypes |
| M7 | Hardening | Compatibility, performance and security |
| M8 | Public beta | Release artifacts, docs and contribution workflow |

Each milestone file defines deliverables, dependencies, acceptance criteria and test evidence.
